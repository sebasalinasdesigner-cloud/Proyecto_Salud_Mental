🧠 Predictor Interactivo de Adicción

Aplicación desarrollada con Streamlit que carga el modelo de Machine Learning entrenado y genera una predicción del nivel de adicción a redes sociales en tiempo real según los datos del estudiante.

  • Edad, horas de uso diario y horas de sueño
  • Puntaje de salud mental y conflictos sociales
  • Indicador de riesgo: Bajo 🟢 · Moderado 🟡 · Alto 🔴
  • Powered by scikit-learn · R² = 0.9497

  Si el predictor no aparece, ejecuta este comando en tu terminal:

streamlit run app.py

La app se abrirá automáticamente en http://localhost:8501 y también se mostrará embebida aquí abajo.
